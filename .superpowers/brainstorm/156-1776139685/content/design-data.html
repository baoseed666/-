🗃️ 核心数据模型（PostgreSQL）

users
id UUID PK
phone VARCHAR(20) UNIQUE
wechat_openid VARCHAR UNIQUE NULL
nickname VARCHAR(50)
avatar_url TEXT
total_saved DECIMAL(10,2) DEFAULT 0
rank_title VARCHAR(20)
created_at TIMESTAMP
challenges
id UUID PK
user_id UUID FK→users
input_text TEXT
budget DECIMAL(10,2)
people_count INT
city VARCHAR(20)
status ENUM(active/completed/failed)
saved_amount DECIMAL(10,2)
created_at TIMESTAMP
challenge_tasks
id UUID PK
challenge_id UUID FK→challenges
type ENUM(main/side/hidden)
description TEXT
tips TEXT[]
shop_id UUID FK→shops NULL
status ENUM(pending/done/skipped)
sort_order INT
shops
id UUID PK
name VARCHAR(100)
category VARCHAR(30)
city VARCHAR(20)
district VARCHAR(30)
lat / lng DECIMAL(10,7)
avg_price DECIMAL(8,2)
rating DECIMAL(3,1)
discounts JSONB
open_hours JSONB
scraped_at TIMESTAMP
battle_reports
id UUID PK
challenge_id UUID FK→challenges
headline TEXT
rank_title VARCHAR(30)
percentile INT
image_url TEXT
created_at TIMESTAMP
lbs_requests
id UUID PK
user_id UUID FK→users
shop_id UUID FK→shops NULL
lat / lng DECIMAL(10,7)
tags TEXT[]
status ENUM(waiting/matched/expired)
matched_user UUID FK→users NULL
expires_at TIMESTAMP

🔌 API 端点设计

# Auth
POST /auth/sms/send 发送验证码（Demo固定123456）
POST /auth/sms/verify 验证码登录 → JWT
POST /auth/wechat/callback 微信OAuth回调 → JWT
POST /auth/refresh 刷新 Access Token
# Challenge（AI核心）
POST /challenges 创建挑战 → AI生成任务（SSE流式输出）
GET /challenges/:id 获取挑战详情+任务列表
PATCH /challenges/:id/tasks/:tid 更新任务状态
POST /challenges/:id/complete 完成挑战，触发战报生成
# Shop
GET /shops ?city=&category=&lat=&lng=&limit=
GET /shops/:id 店铺详情+优惠信息
# Battle Report
GET /reports/:id 战报详情
GET /reports/:id/image PNG海报（直接返回图片）
# LBS
POST /lbs/request 上报位置+需求，加入匹配池
WS /lbs/match WebSocket：实时推送匹配结果
# Leaderboard
GET /leaderboard ?city=&limit= 省钱排行榜
GET /heatmap ?city= 今日热力图数据
GET /stats/city ?city= 城市今日省钱统计
# Scraper Admin（内部）
POST /admin/scraper/start 触发爬虫任务（指定城市/品类）
GET /admin/scraper/status 查看爬虫队列状态
