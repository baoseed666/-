设计第一节：模块范围 & 11天排期

确认功能边界，避免后期范围蔓延

🗂️ 7大核心模块

① AuthModule
Phase 1: 手机号+短信验证码
Phase 2: 微信网页授权（后补）
JWT Session + Redis 存储
② ChallengeModule（AI核心）
输入: 预算+人数+活动+城区
DeepSeek生成3套方案+子任务
Claude兜底复杂推理
③ ShopModule
店铺搜索（城市/品类/距离）
优惠信息 / 隐藏折扣缓存
数据来自 ScraperWorker
④ ScraperWorker
Puppeteer + 大众点评
Bull队列 + Redis
多城市/多品类并发，限速1-3 req/s
⑤ BattleReportModule
AI生成战报文案（HP/MP游戏术语）
Sharp生成PNG分享图
OSS/本地存储分享链接
⑥ LBSModule
上报坐标 + 需求标签
100m内相似需求匹配
WebSocket推送匹配结果
⑦ LeaderboardModule
城市省钱热力图数据 / 个人省钱总榜 / 段位称号系统（薅羊毛学徒→抠门大王）/ 今日城市统计

📅 11天开发排期

Day 1-2
项目脚手架 / PostgreSQL+Redis / Auth(SMS) / 爬虫框架 + Bull队列 / DB Schema全部建好
Day 3-4
爬虫跑通大众点评（餐饮/娱乐/购物）多城市 / ShopModule API / 数据入库验证
Day 5-6
ChallengeModule AI核心 / DeepSeek Prompt工程 / 3套方案+主线+支线+隐藏任务生成
Day 7-8
前端主流程：输入页→任务面板→店铺匹配→完成确认 / 游戏化UI组件
Day 9
BattleReport生成 / Sharp海报 / 排行榜 / 称号系统
Day 10
LBS拼单WebSocket / 城市热力图 / 联调全流程
Day 11
Playwright E2E测试 / lint + build / Demo数据填充 / 演示脚本排练
⚠️ 范围外（不做）
支付系统 / 真实返现 / 短信实际发送（用固定验证码 123456 演示） / 小程序审核 / 微信登录（后补）
